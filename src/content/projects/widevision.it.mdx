## Problema

Unificare in un'unica piattaforma il noleggio e la vendita di attrezzatura fotografica/cinematografica — categorie eterogenee (corpi, ottiche, illuminazione, audio, supporti), prezzi giornalieri/settimanali, calendario disponibilità, gestione resi e cauzioni.

## Architettura

- **Laravel** come framework principale (controller, Eloquent ORM, queue, scheduling).
- **MySQL** per persistenza: catalogo, inventario, prenotazioni, ordini, utenti.
- **Bootstrap** per il design system del frontend, responsive mobile-first.
- Search engine interno con filtri per categoria, disponibilità per data, prezzo.
- Sistema di prenotazione con calendar lock per evitare overbooking.
- Area cliente con storico noleggi, ricevute, gestione cauzioni.
- Area admin per gestione catalogo, inventario, prezzi, report.

## Stack

PHP · Laravel · MySQL · Bootstrap · Blade · Eloquent

## Risultato

Piattaforma in produzione, sostituisce il workflow precedente (telefono + email + spreadsheet) con un sistema self-service. Riduce il tempo medio per chiudere un noleggio e abbatte gli errori di doppia prenotazione.
