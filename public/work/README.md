# Project covers

Place project hero images here. They are referenced from MDX frontmatter via the `cover` field:

```yaml
cover: /work/widevision-cover.jpg
```

## Required

- `widevision-cover.jpg` — WideVision HUB hero screenshot (≈ 1600×900 recommended, JPG ≤ 300 KB).
  The Astro `<Image>` pipeline is not used here so a single optimized JPG is enough.

If the file is missing, the project card falls back to the generic SVG glyph.
